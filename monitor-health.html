Monitor Health

Answers “can I trust the network pages right now?” — separate from network health, because a dead collector is indistinguishable from a site-wide outage.

Designed, not yet built
Planned scope

Organised as one panel per integration, because collection failures are independent across integrations and shared within one. Collection mode is a subsection inside a panel, not the spine.

  • Cisco Meraki — pull: request rate against its org limit, headroom, throttle events, poll-cycle completion, bulk vs per-device call ratio.
  • Juniper Mist — pull, plus push for the WebSocket: connection and reconnect state, per-subscription state, arrival rate against baseline, last-message age, sequence gaps, consumer lag, snapshot recency.
  • kTranslate — pull (SNMP) and push (syslog, flow), plus agent fleet with precomputed per-agent blast radius, and the health of the hosts the agents run on.
  • Coverage model — not a failure domain; the per-source contract the network pages read for their panel headers.
  • Monitoring-edge incident roots — the diagnosis the org page’s handoff row links to.
