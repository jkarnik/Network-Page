Monitor Health

Answers “can I trust the network pages right now?” — separate from network health, because a dead collector is indistinguishable from a site-wide outage.

Designed, not yet built
Planned scope
  • Pull / polling health — request rate against limit, headroom, throttle events, poll-cycle completion, bulk vs per-device call ratio.
  • Push / streaming health — connection and subscription state, message arrival against baseline, heartbeat and last-message age, sequence gaps, consumer lag, snapshot recency.
  • Agent fleet — kTranslate inventory, ingest rates, orphaned devices, precomputed per-agent blast radius.
  • Agent host hardware — CPU, memory, disk, restarts, capacity headroom.
  • Coverage model — the per-source contract the network pages read for their panel headers.
  • Monitoring-edge incident roots — the diagnosis the org page's handoff row links to.
